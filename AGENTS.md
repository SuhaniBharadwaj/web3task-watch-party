# Web3Task Watch Party

## Project Goal
Build the Web3Task Round 2 Watch Party assignment as a real full-stack web application.

## Development Rules
- Use React for the frontend.
- Use Node.js and Express.js for the backend.
- Use MongoDB for persistent data.
- Use Socket.IO for real-time communication.
- Use the YouTube IFrame Player API for video playback.
- Build real working functionality, not mock functionality.
- Keep the code understandable for a fresher.
- Do not unnecessarily rewrite working code.
- Validate user input on both frontend and backend.
- Never expose secrets in frontend code.
- Keep authentication and authorization on the backend.
- Test each major feature before moving to the next.
- Explain important architectural decisions.
- Update PROJECT_STATUS.md after major milestones.
